
# Healthcare Urgency Classification Using NLP

## Project Overview
This project aims to classify healthcare cases based on urgency using Natural Language Processing (NLP) techniques.

## Dataset
The dataset was collected from GitHub and contains medical-related text used for classification.

## Tools & Technologies
- Python
- Pandas
- Scikit-learn
- TF-IDF
- NLP

## Project Steps
- Data preprocessing
- Text cleaning and lemmatization
- Feature extraction using TF-IDF
- Model training and evaluation

## Results
The model was able to classify urgency levels based on text data with good performance.
